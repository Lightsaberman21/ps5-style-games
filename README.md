# PlayStation Mini Hub

A PS5-inspired browser game hub with local profiles/passwords and 10 playable mini-games. Everything runs client-side and saves in localStorage on the device.

Games: Snake, Pong, Breakout, Tetris, Memory Match, Tic-Tac-Toe, Minesweeper, 2048, Space Blaster, Flappy.

Open `index.html` in a modern browser.
